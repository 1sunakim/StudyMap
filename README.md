# StudyMap

StudyMap 是一个面向大学生的 AI 课程知识地图原型。

它把课程内容组织成可展开的知识导图，每个知识点都可以打开查看详细内容，并预留了 AI 撰写解释、自测题生成、复习清单等学习辅助功能。

## 当前功能

- 课程知识地图展示
- 地图节点显示知识点名称和简介，名称字体更醒目
- 点击节点查看和编辑知识点详情
- 详细内容输入区支持浅色占位提示，输入后自动消失
- 在知识地图区域添加或删除知识点
- 在多张思维导图之间切换，选择当前要编辑的导图
- 新建空白思维导图
- 导入已有 JSON 思维导图
- 知识地图画布支持拖动、缩放、滚轮缩放和动态扩展
- 长按知识点后可拖动调整节点位置，连线会实时更新
- 知识点学习链会按结构顺序展示学习状态，并支持点击跳转
- 详细内容拆分为“知识点介绍”和“题目与例题”
- AI 生成内容先进入临时草稿区，用户确认后再放入正式文本
- 记录保存、添加、AI 生成、导出等历史修改内容和时间
- 标记学习状态：未学、学习中、已掌握
- 切换学习状态后，节点卡片颜色、统计和复习清单会同步刷新
- 根据掌握状态生成复习清单
- 本地模拟 AI 撰写解释
- 本地模拟 AI 生成自测题
- 导出 JSON 数据，包含多张导图、知识点、题目、节点位置和历史记录

## 使用方式

直接打开 `index.html` 即可运行。

当前版本不需要安装依赖，也不需要后端服务。AI 功能暂时是前端本地模拟，后续可以替换为真实模型 API。
